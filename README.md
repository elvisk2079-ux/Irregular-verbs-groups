# Неправильные глаголы по группам чередований (B1–B2)

«Чемоданчик учителя английского» · 130 глаголов · 16 групп

- `index.html` — главная: распределение всех глаголов по группам
- `groups/01.html … 16.html` — тренажёр для каждой группы: таблица с озвучкой, карточки, три формы по переводу, диктант на слух, выбор формы, предложения, история с пропусками
- `groups.md`, `verbs.csv` — распределение глаголов (для печати и Excel)
- `src/data.py` — все глаголы, транскрипция, переводы, предложения и тексты; `python3 src/build.py` пересобирает сайт
