# Неправильные глаголы по группам чередований (B1–B2)

## 👉 [Открыть тренажёр](https://elvisk2079-ux.github.io/Irregular-verbs-groups/)

https://elvisk2079-ux.github.io/Irregular-verbs-groups/

«Чемоданчик учителя английского» · 109 глаголов · 16 групп (таблица «Irregular Verbs for B2» + bind)

- `index.html` — главная: распределение всех глаголов по группам
- `groups/01.html … 16.html` — тренажёр для каждой группы: упражнения идут подряд одно за другим — таблица, карточки с озвучкой, недостающие формы, Past Simple, Present Perfect и пассив, ловушка did/didn't, выбор формы, поиск ошибок, перевод, текст
- `groups.md`, `verbs.csv` — распределение глаголов (для печати и Excel)
- `src/data.py`, `src/extra.py` — все глаголы, транскрипция, переводы, предложения и тексты; `python3 src/build.py` пересобирает сайт
