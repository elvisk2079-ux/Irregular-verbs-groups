-d / -l / -n → -t

В конце появляется -t

send – sent – sent

V2 = V3. Гласная не меняется, меняется только конец: -d → -t (send → sent, build → built) или к -l / -n добавляется -t (smell → smelt, learn → learnt).

Глаголы burn, learn, spell, smell, spill в американском английском правильные: burned, learned… Оба варианта верны.
