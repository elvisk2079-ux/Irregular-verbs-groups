-d / -n → -t

В конце появляется -t

send – sent – sent

V2 = V3. Гласная не меняется, меняется только конец: -d → -t (send → sent, build → built) или к -n добавляется -t (burn → burnt, learn → learnt).

Глаголы burn и learn в американском английском правильные: burned, learned… Оба варианта верны.
